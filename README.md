# Personal Task Manager

A modern, lightweight personal task management web application built with **Laravel**, **SQLite**, and **Bootstrap 5**. Designed for seamless daily activity tracking with a clean custom teal UI theme.

## Features
- **Dashboard Overview:** Real-time summary metrics for Total Tasks, In Progress (Pending), and Completed tasks.
- **Full CRUD Operations:** Create, read, update, and delete tasks easily.
- **Status Tracking:** Toggle and update task statuses (Pending / Completed).
- **Form Validation & Error Handling:** Ensures data integrity when submitting tasks.
- **Modern UI / UX:** Built with Bootstrap 5, custom gradients, and a sleek Deep Teal & Bright Teal aesthetic.

## Tech Stack
- **Backend:** PHP / Laravel
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, Bootstrap 5, Blade Templates, Bootstrap Icons
